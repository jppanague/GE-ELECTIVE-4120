# ✨ Activity 5: AI Tools Activity
> *Exploring AI image generation through prompt writing using Gemini*

---

### ✦ About the Activity
This activity focused on using **Gemini** to generate scenery images through written prompts. I first used a simple prompt, "Make me a scenery," and then created a second, more detailed prompt describing green mountains, a crystal-clear lake, colorful wildflowers, tall trees, sunlight, birds, and mist. I compared the two generated images based on how well they followed the prompts, their visual details, and their usefulness.

### ✦ What Have I Learned?

Through this activity, I gained the following knowledge and skills:

- **Prompt Writing:** Learned that clear and specific instructions help an AI tool generate images that better match the intended idea.
- **AI Output Evaluation:** Gained experience comparing AI-generated images based on their accuracy, visual details, and usefulness.
- **Creativity & Communication:** Understood how descriptive words about objects, colors, lighting, and atmosphere can guide the generated result.
- **Problem-Solving:** One challenge was that my first prompt was too general. I addressed this by writing a more specific second prompt that included the scenery elements and visual qualities I wanted.
- **Future Application:** I can apply this skill to future academic and creative projects by planning prompts carefully, adding relevant details, and reviewing the generated output.

---

### ✦ Key Takeaway
This activity taught me that the quality of an AI-generated image depends partly on how clearly the user communicates their ideas. A well-written prompt can make the result more detailed, accurate, and useful.
