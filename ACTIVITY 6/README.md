# 💰 Activity 6: Replit AI Activity
> *Creating a Personal Budget Planner Website Using AI*

---

### ✦ About the Activity
This activity focused on creating a functional personal budgeting website called **Pennywise Budget Planner** using Replit AI. The goal was to develop a user-friendly platform that helps users manage their finances by tracking monthly income, expenses, remaining balance, and savings. The website includes features such as transaction management, monthly budgets, savings goals, financial reports, and settings, using a clean and minimalist design.

### ✦ What Have I Learned?

Through this activity, I gained the following knowledge and skills:

- **AI-Assisted Website Development:** Learned how to use Replit AI to generate and develop a functional website based on written instructions.
- **Financial Management:** Gained a better understanding of budgeting, tracking expenses, managing income, and setting savings goals.
- **Web Design & Organization:** Learned the importance of creating a clean, organized, and user-friendly interface with accessible features.
- **Problem-Solving:** One challenge was making sure the website included the requested features and worked properly. I addressed this by providing detailed prompts and reviewing the generated website.
- **Future Application:** I can apply these skills in developing other useful websites and improving my understanding of web development and AI-assisted programming.

---

### ✦ Key Takeaway
This activity taught me that technology and AI can make everyday tasks, such as financial management, easier and more organized. A good website should not only have an attractive design but also provide practical solutions to real-life problems.
