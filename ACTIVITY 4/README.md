# 📝 Activity: Google Docs Reporting
> *Exploring the features and functions of Google Docs*

---

### ୨୧ About the Activity
This activity focused on discussing and presenting **Google Docs**, an online word-processing application developed by Google. The presentation aimed to introduce its features, functions, and practical uses in creating, editing, formatting, and sharing documents. It also highlighted how Google Docs supports collaboration by allowing multiple users to work on the same document and access their files online.

### ୨୧ What Have I Learned?

Through this activity, I gained the following knowledge and skills:

- **Digital Literacy:** Learned more about Google Docs and its role in creating and managing digital documents.
- **Document Management:** Gained knowledge of the different tools used for writing, editing, formatting, and organizing documents.
- **Collaboration:** Understood how Google Docs allows users to share documents and collaborate with others in real time.
- **Presentation Skills:** Improved my ability to organize information, explain digital tools, and communicate important details during a report.
- **Future Application:** I can apply these skills in preparing nursing assignments, group projects, reports, and other academic documents while continuing to explore the different features of Google Docs.

---

### ୨୧ Key Takeaway
This activity taught me that Google Docs is a practical tool for making academic and professional tasks more convenient and organized. It also showed me how digital platforms can improve productivity, accessibility, and collaboration.
