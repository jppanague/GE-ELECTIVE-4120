# 📊 Activity: Grades and Class Performance Report
> *Organizing, calculating, and interpreting students' academic performance*

---

### ✦ About the Activity
This activity focused on organizing students' grades and creating a class performance report using Microsoft Excel. It involved encoding individual grades, calculating student averages, and identifying the class average, highest grade, lowest grade, and top-performing student. The results were presented in an organized table to make the academic performance easier to understand and interpret.

### ✦ What Have I Learned?

Through this activity, I gained the following knowledge and skills:

- **Data Organization:** Learned how to arrange students' names and grades systematically using a spreadsheet.
- **Basic Spreadsheet Skills:** Gained experience calculating individual averages and the overall class average using mathematical formulas.
- **Data Analysis:** Learned how to interpret numerical results by identifying the highest and lowest grades and determining the top-performing student.
- **Problem-Solving:** One challenge was ensuring that the calculations were accurate and properly organized. I addressed this by reviewing the encoded grades and checking the formulas and computed averages.
- **Future Application:** I can apply these skills in managing academic records, organizing information, and analyzing data in future school activities and professional tasks.

---

### ✦ Key Takeaway
This activity taught me that spreadsheet tools are useful for organizing and analyzing information efficiently. Accuracy in data entry and computation is important in producing reliable reports and making informed interpretations.
